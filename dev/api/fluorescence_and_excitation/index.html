Excitation & Leaf Fluorescence

Inelastic chlorophyll fluorescence optics are factored into three composable stages that operate on CPU scalars/arrays and KernelAbstractions GPU backends without embedding photosynthetic physiology:

  1. Constituent absorption partitioning (partition_absorption) splits total leaf material absorptance at each excitation wavelength across pigments, water, and dry matter in proportion to their specific optical depths.
  2. Antenna selection & photosystem allocation (antenna_excitation, photosystem_excitation) converts absorbed spectral photons into photosynthetic antenna absorption (ChlorophyllOnly, CarotenoidAntenna, MultiChlorophyllAntenna) and PSII/PSI excitation rates ready for physiological models such as LeafPhotosynthesis.jl.
  3. Internal photon escape & emission spectra (diffuse_plate_optics, dorsiventral_plate_optics, leaf_emission_fates, emission_probabilities) propagate internally emitted fluorescence photons through 1-zone (RegularPlateEscape) or 2-zone (DorsiventralPlateEscape) mesophyll stacks with exact photon conservation (front + back + reabsorbed = 1 for all t ∈ (0, 1]) and Stokes-valid emission support.

Constituent Absorption Partitioning

Physical rule for assigning spectral material absorption to constituents.

CanopyOptics.HomogeneousAbsorption — Type
HomogeneousAbsorption()

Assign absorption in one wavelength bin in proportion to constituent absorption coefficients. All constituents must have the same proportions along every optical path. This does not describe spatially segregated pigments in layered mesophyll.

source
CanopyOptics.AbsorptionPartitionResult — Type
AbsorptionPartitionResult(total_absorbed, constituents, fractions, status)

Spectral absorbed photons and their named constituent contributions, in the same photon-flux units and area convention as the caller's input. constituents is a concrete NamedTuple, so adding an absorber does not change a fixed field layout. fractions retains unitless probabilities before photon multiplication, so selection does not lose pigment identity when constituent photons underflow. Fractions are undefined (NaN) for absent absorption coefficients; absorbed photons are then zero. Invalid results contain NaN payloads; absorption_valid checks status. This result owns no wavelength grid, device storage or physiological state.

CanopyOptics.partition_absorption — Function
partition_absorption(HomogeneousAbsorption(), absorbed_photons, coefficients)

Partition the supplied total absorbed photons at one wavelength/bin using named constituent concentration × absorption-coefficient products in a common optical-depth convention. Inputs must share FT. No PROSPECT database or leaf composition is chosen here; their assembly belongs to the host.

For each constituent, Qi = Qabs ki / sum(ki). Scale the nonnegative coefficient products before summing to avoid overflow. This defines constituent probabilities; it never normalizes or alters the supplied optical absorption budget. Obtain Qabs independently from the optical solver (e.g. `prospectbudget`).

Negative/nonfinite inputs return AbsorptionInvalidInput. An empty/all-zero coefficient set with nonzero Qabs returns AbsorptionIncompatibleInput; with Qabs=0 it returns AbsorptionNoMaterial. Zero illumination of absorbing material is instead AbsorptionPartitionValid. All paths are scalar and nonthrowing for same-FT numerical inputs. Mixed-precision tuples have no implicit conversion.

source
CanopyOptics.absorption_valid — Function
absorption_valid(result::AbsorptionPartitionResult) -> Bool

Return true when result represents a valid absorption partition, including material with zero absorption coefficient (AbsorptionNoMaterial).

CarotenoidAntenna(transfer_fraction)

Chlorophyll absorption plus an explicit fraction of carotenoid-absorbed photons enters the antenna pool. Requires :chlorophyll and :carotenoids contributions. MultiChlorophyllAntenna(; chlb_transfer = 1, carotenoid_transfer = 0)

CanopyOptics.antenna_excitation — Function
antenna_excitation(selection, partition)

Selected antenna photons in the partition's photon/area units, before photosystem allocation. Invalid partition status, a missing required pigment name or an invalid selection returns a typed NaN. Unselected absorption remains in partition; it is not removed from material energy accounting or assigned to a physiological KN.

Custom AbstractAntennaSelection types implement select_absorbed_photons for a valid partition, returning a scalar of the same FT. Neither a fixed absorber list nor a wavelength database is imposed on custom selections.

source
CanopyOptics.select_absorbed_photons — Function
select_absorbed_photons(selection, partition)

Extension hook for an antenna selection applied to a valid absorption partition. Implementations return selected photons with the input FT, or typed NaN for missing required constituents. Normally call antenna_excitation, which checks status and the returned photon bound. Built-in selections accumulate the smaller selected or unselected probability before multiplying by photons, using the complementary probability identity near total selection. This retains zero-pigment and all-selected limits even if constituent photon amounts have underflowed. This equivalent probability identity improves rounding without clipping, changing constituent diagnostics or repairing an optical flux budget.

source
CanopyOptics.photosystem_excitation — Function
photosystem_excitation(antenna_photons, allocation_fraction)

Allocate antenna photons to one declared photosystem, with an explicit finite fraction in [0,1]. Values refer to the same wavelength bin and photon/area units; the caller chooses and integrates the spectral domain. A PSII allocation is applied once here, not again in a leaf model receiving the resulting PSII excitation. Invalid numerical inputs return typed NaN; no empirical fraction is supplied.

Internal Leaf Photon Escape (1-Zone & 2-Zone Plates)

CanopyOptics.AbstractLeafBirthProfile — Type
AbstractLeafBirthProfile

Normalized internal photon birth-depth distribution, independent of yield and spectrum.

source
CanopyOptics.UniformBirthProfile — Type
UniformBirthProfile()

Uniform photon production over dimensionless depth 0 ≤ z ≤ 1.

source
CanopyOptics.ExponentialBirthProfile — Type
ExponentialBirthProfile(excitation_depth, forward_amplitude, backward_amplitude)

Conditional birth density proportional to forward_amplitude*exp(-a*z) + backward_amplitude*exp(-a*(1-z)), where a = excitation_depth and z=0 is the fixed anatomical front face. These amplitudes weight excitation-depth contributions, not emission directions. The host constructor conditions finite nonnegative relative amplitudes on their positive sum, using scaling to avoid overflow and retaining both proportions when representable (extreme amplitude ratios can underflow). Depth must be finite and nonnegative; all three arguments have the same FT.

For a homogeneous, front-illuminated regular plate, the relative amplitudes are (1, r_exc*exp(-a)). The effective depth follows TOTAL material attenuation; depth-independent pigment allocation and physiological yield cancel on conditioning. This effective exponential closure is not an exact angular solution inside a leaf.

source
CanopyOptics.DorsiventralBirthProfile — Type
DorsiventralBirthProfile(
    adaxial_weight, abaxial_weight,
    adaxial_excitation_depth, adaxial_forward, adaxial_backward,
    abaxial_excitation_depth, abaxial_forward, abaxial_backward,
)
DorsiventralBirthProfile(adaxial_weight, adaxial_profile, abaxial_weight, abaxial_profile)
DorsiventralBirthProfile(adaxial_weight, abaxial_weight)

Two-zone normalized internal photon birth-depth distribution for DorsiventralPlateEscape.

Local dimensionless depth ζ_i ∈ [0, 1] runs anatomically adaxial → abaxial in both zones:

  • Zone 1 (adaxial / palisade): ζ_1 = 0 at the outer adaxial epidermis and ζ_1 = 1 at the internal palisade–spongy boundary, with conditional density proportional to adaxial_forward * exp(-a_1 * ζ_1) + adaxial_backward * exp(-a_1 * (1 - ζ_1)).
  • Zone 2 (abaxial / spongy): ζ_2 = 0 at the internal palisade–spongy boundary and ζ_2 = 1 at the outer abaxial epidermis, with conditional density proportional to abaxial_forward * exp(-a_2 * ζ_2) + abaxial_backward * exp(-a_2 * (1 - ζ_2)).

Reversing the anatomical leaf orientation (adaxial ↔ abaxial) therefore maps (w_1, a_1, f_1, g_1) ↔ (w_2, a_2, g_2, f_2), swapping front and back escape while leaving reabsorbed invariant.

The two-argument DorsiventralBirthProfile(adaxial_weight, abaxial_weight) constructor creates a piecewise-uniform birth profile (a_1 = a_2 = 0) with normalized zone weights. Passing UniformBirthProfile directly to leaf_emission_fates on a DorsiventralPlateEscape weights both zones equally (1/2, 1/2).

source
CanopyOptics.RegularPlateEscape — Type
RegularPlateEscape(emission_depth, interface_transmission)

Symmetric regular plate with finite effective emission optical depth b ≥ 0 and the internal-interface-to-outside photon transmission probability 0 < t ≤ 1. The within-plate traversal survival is exp(-b); it is distinct from t. Both boundaries have reflection 1-t. Emission starts equally toward either face. Reflection paths end at the front face, back face or material reabsorption. Perfectly trapping interfaces (t=0) are excluded from this three-fate contract.

Preparation/validation occurs on the host. The scalar application is allocation free and supports Float32/Float64 CPU/CUDA; no optical database, intrinsic emission spectrum, physiological yield, grid or device is owned by this object.

source
CanopyOptics.DorsiventralPlateEscape — Type
DorsiventralPlateEscape(adaxial_depth, abaxial_depth, adaxial_transmission, abaxial_transmission[, interface_transmission = 1])

Two-zone dorsiventral internal emission escape kernel with finite nonnegative zone emission optical depths adaxial_depth ≥ 0 (palisade / zone 1) and abaxial_depth ≥ 0 (spongy / zone 2), internal-to-outside diffuse exit transmission probabilities 0 < adaxial_transmission ≤ 1 and 0 < abaxial_transmission ≤ 1, and internal palisade–spongy boundary transmission 0 < interface_transmission ≤ 1 (default 1 for an index-matched mesophyll boundary, or < 1 for an intercellular air-space interface).

Within-zone single-pass survival is exp(-b_i) with isotropic half-space initial emission (1/2 toward either boundary of the birth zone). Reabsorption is terminal with no secondary re-emission, wavelength redistribution, physiological yield, or directional radiance assumption. Photon conservation front + back + reabsorbed ≈ 1 holds to floating-point roundoff without clipping or post-hoc rescaling across normal and subnormal interface transmissions.

This isbits scalar object owns five floating-point values, allocates zero memory on evaluation, and runs identically on CPU and CUDA (Float32/Float64).

source
CanopyOptics.diffuse_plate_optics — Function
diffuse_plate_optics(material_depth, refractive_index)

Prepare one regular PROSPECT plate from finite material optical depth k ≥ 0 and refractive index nr > 1, using the same floating-point type. Return traversal_transmission, traversal_absorptance, effective_depth, interface_entry_transmission and interface_exit_transmission.

Traversal transmission is 2E₃(k) and absorption is evaluated directly near zero. The effective exponential depth is its negative logarithm, computed from direct loss near the conservative limit so a rounded unit transmission does not erase weak absorption. This depth is an internal-source approximation, not angle-resolved propagation. Both interfaces use hemispheric (90-degree) Fresnel transmission, with t_exit=t_entry/nr². The entry convention differs from default PROSPECT's first-surface 40-degree cone and is not a solar zenith angle.

This is host preparation, tested in Float32/Float64 over the native optical database's refractive-index range. The nearly index-matched limit of the legacy Fresnel expression is unsupported; invalid computed interface probabilities are rejected. There is no CUDA or ForwardDiff contract for this helper. Use its prepared values in RegularPlateEscape and ExponentialBirthProfile for CPU/CUDA application. Zero traversal transmission from underflow is rejected instead of floored; the scalar escape core can accept independently resolved finite effective depths beyond this preparation domain.

No plate count, material composition, wavelength grid, intrinsic spectrum, physiological yield or source normalization is chosen here. In particular, this does not reconstruct a fractional PROSPECT remainder's internal interfaces.

source
CanopyOptics.dorsiventral_plate_optics — Function
dorsiventral_plate_optics(
    k_adaxial, k_abaxial, nr;
    surface_adaxial = ConeSurface(40, 1),
    surface_abaxial = ConeSurface(40, 1),
    n_surface_adaxial = nr,
    n_surface_abaxial = nr,
    hemispherical = false,
    internal_air_gap = false,
)

Host preparation helper mapping finite nonnegative palisade (k_adaxial) and spongy (k_abaxial) material optical depths and aqueous mesophyll refractive index nr > 1 into effective exponential emission depths, outer entry/exit transmissions, internal palisade–spongy boundary transmission, and a prepared DorsiventralPlateEscape.

Outer diffuse internal exit transmissions t_exit = t_hem_ext(n_eff, σ) / nr² obey isothermal detailed-balance étendue conservation (n_eff = n_scale * n_surface_face), supporting both ConeSurface and RoughDielectricSurface as well as epicuticular wax refractive indices (n_surface_adaxial, n_surface_abaxial). hemispherical selects hemispherical (90°) vs 40°-cone external entry transmission (adaxial_entry_transmission, abaxial_entry_transmission) for excitation transport; diffuse internal exit transmission is always hemispherical.

For the internal boundary between zones:

  • internal_air_gap = false (default): interface_transmission = 1 (unbroken index-matched mesophyll boundary, exact two-sublayer slab limit).
  • internal_air_gap = true: symmetric diffuse mesophyll (nr) → intercellular air space (n = 1) → mesophyll (nr) transmission t_gap = t90 / (nr² * (2 - t90)) where t90 = calctav(90, nr), accounting for multiple internal reflections within the air gap.
source
CanopyOptics.leaf_emission_fates — Function
leaf_emission_fates(escape, birth)

Return (front, back, reabsorbed) probabilities per already-produced internal photon. Birth orientation uses fixed anatomical faces. Reabsorption is terminal; no secondary emission, wavelength redistribution, absorptance or yield is applied. Photon conservation holds to floating-point roundoff without clipping or rescaling. Hemispheric face totals do not specify directional canopy radiance.

Built-in methods require the escape and exponential birth profile to share FT; UniformBirthProfile() has no numeric parameters. Additional escape or birth models can define methods without altering a LeafModel or host grid.

Conditional Fluorescence Emission Spectra

CanopyOptics.TabulatedPhotonSpectrum — Type
TabulatedPhotonSpectrum(wavelength_nm, relative_photon_mass)

Host-prepared discrete photon measure on finite, positive, strictly increasing wavelengths in nm. Both vectors must have the same floating-point element type. Masses are finite and nonnegative with at least one positive entry; they need not sum to one. For a tabulated photon density, the caller must first multiply by the corresponding quadrature measures exactly once.

The constructor copies its inputs and retains raw masses so a rare supported tail is not lost by premature normalization. The vectors remain mutable Julia arrays; emission_probabilities revalidates them before preparation. This object contains neither absorptance nor fluorescence yield, and is not a device kernel argument.

source
CanopyOptics.AbstractEmissionSupport — Type
AbstractEmissionSupport

Excitation-dependent emission support rule; extend emission_allowed.

source
CanopyOptics.StrictStokes — Type
StrictStokes()

Permit only emission wavelengths strictly longer than excitation. Equality is excluded. This explicit approximation omits thermal anti-Stokes excitation. Conditioning changes the reference spectral shape while retaining the separately prescribed physiological photon yield; removed weights do not establish additional quenching or heat production.

source
CanopyOptics.emission_allowed — Function
emission_allowed(support, emission_nm, excitation_nm) -> Bool

Scalar extension hook for an AbstractEmissionSupport. Host preparation supplies finite positive wavelengths of the same floating-point type. Implementations return a Boolean and can be device compatible without depending on a canopy, physiology model, or spectrum storage layout.

source
CanopyOptics.emission_probabilities — Function
emission_probabilities(spectrum, support, excitation_nm)

Prepare conditional photon probabilities on the spectrum's original grid, with exact zeros outside the explicit support. Excitation must be finite, positive, and have the same floating-point type as the table. Empty retained support is an error, not an inactive physical source; callers skip genuinely inactive sources before requesting a conditional spectrum.

Select raw relative masses before max-scaled normalization, preserving a small retained tail even when excluded weights are vastly larger. The result is a host vector in the table's precision that can be transferred to any backend. No yield, absorptance, energy conversion, or spectral-bin width is applied here. Convert photon outcomes to energy using their emission wavelengths, not excitation.
