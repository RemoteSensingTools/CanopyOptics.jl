API Reference

This section documents all exported and public types, constants, and functions in CanopyOptics, grouped by physical domain rather than alphabetical order.

CanopyOptics — Module
CanopyOptics

Canopy radiative-transfer utilities.

Canopy scattering matrices use Z[i_out, j_in]: rows are outgoing streams and columns are incoming streams; Z⁺⁺ is same-sign transmission and Z⁻⁺ is sign-change reflection. Bi-Lambertian kernels follow vSmartMOM's atmospheric phase-matrix convention: the scalar single-scattering albedo is not folded into Z, so conservative bi-Lambertian leaves satisfy

\[\sum_i w_i\,(Z^{++}_{ij} + Z^{-+}_{ij}) \simeq 2 .\]

Specular kernels carry their Fresnel/roughness strength in the returned contribution. Layer solvers that multiply by a separate ϖ need a matching effective albedo when using specular components.

Conventions

  • Exported vs. public bindings: Symbols shown unqualified (prospect_budget, compute_Z_matrices) are exported by using CanopyOptics. Lower-level optical and geometric primitives declared public on Julia 1.11+ (CanopyOptics.calctav, CanopyOptics.Fᵣ, CanopyOptics.H, CanopyOptics.gauleg, etc.) are part of the supported API when qualified with CanopyOptics. or explicitly imported.
  • Precision & automatic differentiation: Leaf budgets, surface optics, and canopy scattering kernels preserve caller floating-point precision (Float32, Float64) and propagate ForwardDiff.Dual tangents with respect to optical and trait parameters.
