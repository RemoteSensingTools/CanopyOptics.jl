FourSAIL Canopy Radiative Transfer

CanopyOptics.FourSAILGeometry — Type
FourSAILGeometry(LAD; sza_deg, vza_deg, raa_deg, quadrature=CanopyQuadrature())

Geometry and leaf-angle coefficients for a 4SAIL canopy solve.

The expensive geometry/LAD integration is wavelength independent and is done once here. foursail! then evaluates one wavelength per kernel work item from leaf reflectance, leaf transmittance, soil reflectance, and LAI.

CanopyOptics.FourSAILResult — Type
FourSAILResult(rddt, rsdt, rdot, rsot, taus, rsos, rsost, rsodt)

Primary 4SAIL reflectance/transmittance factors:

  • rddt: bi-hemispherical reflectance over canopy plus soil
  • rsdt: directional-hemispherical reflectance for solar illumination
  • rdot: hemispherical-directional reflectance for the view direction
  • rsot: bidirectional reflectance factor
  • taus: total solar-direction canopy transmission (tsd + tss)
  • rsos: direct single-scattering canopy contribution
  • rsost: direct/direct contribution (rsos plus directly transmitted soil)
  • rsodt: diffuse/multiple-scattering contribution, so rsot = rsost + rsodt

foursail(leaf_reflectance, leaf_transmittance, soil_reflectance,
         geometry, LAI; hotspot=0)

Allocate outputs and evaluate 4SAIL over all wavelengths. For array inputs the batched kernel path is used; for scalar inputs this returns a scalar FourSAILResult.

CanopyOptics.foursail! — Function
foursail!(rddt, rsdt, rdot, rsot, taus, leaf_ρ, leaf_τ, soil_ρ,
          geom, lai; hotspot=0, mode=:full)
foursail!(result::FourSAILResult, leaf_ρ, leaf_τ, soil_ρ,
          geom, lai; hotspot=0, mode=:full)

Evaluate 4SAIL in place over a wavelength vector using one KernelAbstractions work item per wavelength (or (wavelength, angle) pair for FourSAILGeometrySet) and return the populated FourSAILResult.

soil_ρ may be a scalar, a wavelength vector, or (for FourSAILGeometrySet) a (n_wavelength, n_angle) matrix. All array arguments must use 1-based indexing (throws ArgumentError on offset axes).

In :full mode, rsot = rsost + rsodt decomposes the bidirectional reflectance factor into direct/direct (rsost) and diffuse/multiple-scattering (rsodt) contributions. In :single mode, diffuse equations are skipped (rsot = rsost, rsodt = 0, and diffuse-stream outputs are filled with zero).

See also foursail, FourSAILGeometry, FourSAILGeometrySet.

Reference

Verhoef, W. (1984). Light scattering by leaf layers with application to canopy reflectance modeling: the SAIL model. Remote Sens. Env. 16, 125–141; extended in Verhoef et al. (2007), 4SAIL.

CanopyOptics.LeafUlabyElRayes1987 — Type
LeafUlabyElRayes1987{FT<:Real}(M_g, σ)
LeafUlabyElRayes1987(; M_g = 0.5, σ = 1.27)

Dual-dispersion microwave leaf dielectric model of Ulaby & El-Rayes (1987), combining a non-dispersive residual term, a free-water Debye component, and a bound-water Cole–Cole-like component across 0.2–20 GHz.

Pass to dielectric together with temperature T in K (accepted for signature consistency) and frequency f in GHz.

Fields

  • M_g::FT: gravimetric leaf moisture content in [0, 0.7].
  • σ::FT: effective ionic conductivity of free water in S m⁻¹ (typical 1.27).

Reference

Ulaby, F. T. & El-Rayes, M. A. (1987). Microwave Dielectric Spectrum of Vegetation – Part II: Dual-Dispersion Model. IEEE TGRS 25(5), 550–557; Ulaby & Long (2014), Chapter 11, Section 11-9.

CanopyOptics.dielectric — Function
dielectric(mod::LiquidSaltWater, T, f)

Compute the complex relative permittivity ε(T, f) of saline liquid water following Ulaby & Long (2014, Chapter 4, Eqs. 4.19–4.21), using the +i ε'' loss sign convention.

Arguments

  • mod::LiquidSaltWater: saline water model supplying salinity S in [0, 45] PSU.
  • T::Real: temperature in K (265 <= T <= 310).
  • f::Real: frequency in GHz.

Examples

julia> w = LiquidSaltWater(S = 10.0);

julia> round(dielectric(w, 283.0, 10.0); digits = 4)
51.7925 + 38.323im

true
source
dielectric(mod::LeafUlabyElRayes1987, T, f)

Compute the complex relative permittivity ε(f) of a fresh leaf with gravimetric moisture mod.M_g at frequency f in GHz (0.2 <= f <= 20) following Ulaby & El-Rayes (1987):

\[\varepsilon = \varepsilon_r + v_{fw}\,\varepsilon_{fw} + v_b\,\varepsilon_b .\]

Temperature T in K is accepted for signature consistency with other dielectric methods. Uses the +i ε'' loss sign convention.

Examples

julia> leaf = LeafUlabyElRayes1987(M_g = 0.5);

julia> round(dielectric(leaf, 295.0, 5.0); digits = 4)
14.4008 + 4.6895im

Reference

Ulaby & El-Rayes (1987), IEEE TGRS 25(5), 550–557 (Eqs. 11–14); Ulaby & Long (2014), Chapter 11, Section 11-9.
